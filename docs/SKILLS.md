# SKILLS.md — Intended Technical Capabilities

This file describes the **intended** technical skill/toolset for this project. It does **not** claim all of these are implemented today — the project is in Phase 2 (Information Architecture + Visual Identity) and no application code exists yet.

## Frontend

- **Next.js** — framework (App Router)
- **React** — UI library
- **TypeScript** — language with static typing
- **Tailwind CSS** — styling/utility system

## Animation

- **GSAP** — core animation
- **GSAP ScrollTrigger** — scroll-driven animation
- **Motion / Framer Motion** — React-friendly animation
- **Lenis** — smooth scrolling

## 3D / WebGL

- **Three.js** — WebGL engine
- **React Three Fiber** — Three.js for React
- **Drei** — helpers/components for R3F

## UI

- **Lucide React** — icons
- Responsive design
- Accessibility (semantic markup, focus states, reduced motion)
- Reusable, composable components

## Engineering

- Component architecture
- Performance optimization
- Image optimization
- Responsive behavior
- SEO & metadata
- Git / GitHub workflow
- Deployment (Vercel)

## Usage note

Each skill/tool is expected to be used **only where it serves the content**. Motion must communicate hierarchy or interaction; 3D must have a purpose. Avoid animation for animation's sake and 3D that distracts from content.
